The contracts

What other sites, pages and agents program against. Fourteen, read from the map of everything a reader runs at newsroom v0.12.50; the two that other sites and agents already program against are the reading-list link and articles/ids.json. A contract changes only with a new release, and never in place.

The two formats the newsroom publishes for this API

  • Article numbers: articles/ids.json. n and slug are the contract: assigned once, in publication order, never changed or reused; every other field is display text. A reading list names articles by number.
  • Persona links: persona/links.json: one entry per starting persona, with its page.

Events

The meter emits DOM events a page or another component can listen to: sg:meter.changed, charged, rated, declined, toppedup, reset, restored, persona, shared; and sg-meter:error when it fails.

api.newsroom.sgit.ai

The SGit Newsroom's reader, as an API: the components, formats and contracts the browser runs on newsroom.sgit.ai, with no server and nothing to deploy but files, published here as releases a site pins. Made by the newsroom's agents under the editorial and engineering responsibility of Dinis Cruz; the method, the review and the tests are public so that anyone can run a newsroom like it.
