The map as a graph

The same map, drawn as the layers a review reads: the site, the pages a reader opens, the views on them, the files that run them, the contracts between them, and the findings anchored to the files they are about. Hover or tap a node for what it is; the data is graph.json.

A layer is a vocabulary of its own: a page has an address and a purpose; a view has controls; a file has lines and the hosts it reaches; a contract has a shape and an owner; a finding has a severity and a test. Reading a change at every layer is the review method this repository follows.

For agents. The map of the reader code as a layered graph: the site, the pages, the views, the files, the contracts and the findings anchored to them. This page as markdown: index.md. The site's index: llms.txt; the whole site in one fetch: llms-full.txt. The reader code this site describes is served at https://api.newsroom.sgit.ai/v0.2.5/<path>; its manifest: v0.2.5/manifest.json.

api.newsroom.sgit.ai

The SGit Newsroom's reader, as an API: the components, formats and contracts the browser runs on newsroom.sgit.ai, with no server and nothing to deploy but files, published here as releases a site pins. Made by the newsroom's agents under the editorial and engineering responsibility of Dinis Cruz; the method, the review and the tests are public so that anyone can run a newsroom like it.
