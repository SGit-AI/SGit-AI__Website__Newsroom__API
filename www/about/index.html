About, licence, contact

What this is. The code a reader runs on newsroom.sgit.ai, the reading meter, the reader's personas and lists, subscribe and the encrypted share, the vault layer, search, the wire reader, the passkey lab, released from one repository and served from this host at versioned paths that are never edited after they are published. "API" means client-side: components, formats and contracts the browser runs, with no server and nothing to deploy but files. On this network "API" can also mean the SG/Send server; this is not that.

Who. It is made by the SGit Newsroom's agents under the editorial and engineering responsibility of Dinis Cruz, as every page on newsroom.sgit.ai discloses. The reviews are done by agents and are open to people, which is what the public issues are for. The brief that governs the work is Go slow to go fast, refreshed in briefs/.

Licence. Apache 2.0, for the code, the tests and this site. The articles on newsroom.sgit.ai are the newsroom's and carry their own terms.

Contact. agent@riskmandate.ai, which an agent reads first and a person answers, for pilots and partnerships; issues in the repository for anything about the code, which is where the work happens in any case.

This site. Generated by site/build.py in the repository from markdown pages, the map of what a reader runs, the release manifests and the proof of the move; nothing on it is typed twice. Every page has a .md twin, an agent block, and a place in llms.txt and llms-full.txt. The source of a page is a file a person or an agent can edit; a pull request changes the site.

Names. SGit is the family of tools this comes from: the sgit command line, the SG/Send encrypted vaults, the sites under sgit.ai. The newsroom is one of them.

For agents. About the SGit Newsroom API: a client-side API for a newsroom's reader features, Apache 2.0, maintained in SGit-AI/SGit-AI__Website__Newsroom__API by the newsroom's agents under Dinis Cruz's responsibility; contact agent@riskmandate.ai or the repository's issues; the site is generated from the repository and every page has a markdown twin. This page as markdown: index.md. The site's index: llms.txt; the whole site in one fetch: llms-full.txt. The reader code this site describes is served at https://api.newsroom.sgit.ai/v0.2.5/<path>; its manifest: v0.2.5/manifest.json.
