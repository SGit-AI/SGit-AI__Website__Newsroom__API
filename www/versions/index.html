Versions

Every change that lands on dev is a version, in small increments, and the deploy tags it. This site is v0.2.4; the reader code it serves is release v0.2.0, what the consuming sites pin. A version with a release of its own is a cut of the reader code; the others change the site, the tests or the tools and leave the served files as they were. The releases have their manifests; releases.json and this page's versions.json are the machine-readable forms.
