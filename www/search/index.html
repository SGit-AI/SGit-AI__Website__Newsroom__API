Search

Every page of this site, searched in your browser; and asked, with Chrome’s built-in model or your own OpenRouter key, answered from the passages found. The component is this API’s own, loaded from this host’s release v0.2.5: the site eats what it serves.

    How it works

    There is no search server. When this site is built, site/build.py reads every page it writes and produces two files: docs.json, one entry per page with its title, teaser and headings, and text.json, the text in paragraphs with the section each is in. This page fetches them like any other file and ranks them here, in your browser, with assets/search/search.js from the release this host serves (BM25 over the fields and the paragraphs; a title counts for more than a word in the text). Quotes find an exact phrase. Searching sends nothing anywhere.

    Ask searches the question the same way, takes the best paragraph of each of the top pages, numbers them and gives them to a model with one instruction: answer only from them, cite them by number, and say so when they do not hold the answer. Chrome’s built-in model runs on your machine; your own OpenRouter key is sent to openrouter.ai only. The format of the two files is a contract of this API; the newsroom’s own index is built the same way.

    For agents. Search on api.newsroom.sgit.ai runs in the browser with the API's own search component (assets/search/search.js of the pinned release) over an index this site builds at release time: /search/docs.json (one entry per page: u address, t title, k kind, x teaser, h headings with anchors, i index) and /search/text.json (chunks of [doc index, anchor, text]). Fetch the two files and rank them yourself, or read /llms.txt and the .md twins. This page as markdown: index.md. The site's index: llms.txt; the whole site in one fetch: llms-full.txt. The reader code this site describes is served at https://api.newsroom.sgit.ai/v0.2.5/<path>; its manifest: v0.2.5/manifest.json.

    api.newsroom.sgit.ai

    The SGit Newsroom's reader, as an API: the components, formats and contracts the browser runs on newsroom.sgit.ai, with no server and nothing to deploy but files, published here as releases a site pins. Made by the newsroom's agents under the editorial and engineering responsibility of Dinis Cruz; the method, the review and the tests are public so that anyone can run a newsroom like it.
