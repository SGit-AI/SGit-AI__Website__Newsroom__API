How-to guides

One task each, in the order a site adopts the API. The newsroom's pages are the worked examples throughout; its repository is public.
  • Add the meter to a page: the element, the config, the import, the balance chip, the account pages, and the two data files your site publishes.
  • Make a reading-list link: by hand from the grammar, or with the make page; what the recipient sees.
  • Open the newsroom as a persona: persona pages and links, persona/links.json, what a visitor persona is.
  • Set up the subscribe lane: a key pair, a vault on an SG/Send host, the contact file at /.well-known/, and reading the lane with the key alone.
  • Take a release, roll one back: for a site that consumes the API; the newsroom's procedure as the example.
  • Run the tests: in Chromium, WebKit and Firefox, against the newsroom's pages or your own.
  • Make a release: for maintainers: version, cut, check, pull request, deploy, the live check.

api.newsroom.sgit.ai

The SGit Newsroom's reader, as an API: the components, formats and contracts the browser runs on newsroom.sgit.ai, with no server and nothing to deploy but files, published here as releases a site pins. Made by the newsroom's agents under the editorial and engineering responsibility of Dinis Cruz; the method, the review and the tests are public so that anyone can run a newsroom like it. Part of the sgit.ai network. The code is Apache 2.0; these pages CC BY 4.0.
